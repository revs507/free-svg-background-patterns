# Free SVG background patterns (dark UI)

Two tiny, dependency-free SVG background patterns for dark landing pages, dashboards, slides and Notion covers. Each file is under 400 bytes and tiles with plain CSS.

![Geom + Grain preview](https://assets-2-prod.whop.com/public/uploads/2026-10-05/84c5ceca-a1c5-402f-84f9-178d0e2b56be/image.png)

**Live demo:** https://htmlpreview.github.io/?https://github.com/revs507/free-svg-background-patterns/blob/main/index.html (or open `index.html` locally)

## What's here

| File | Look |
| --- | --- |
| `patterns/waves.svg` | soft slate waves on near-black |
| `patterns/plus.svg` | subtle plus grid on charcoal |
| `index.html` | live demo page using both classes |
| `patterns.css` | both as copy-paste CSS classes (inline data URIs, no requests) |

## Use

```html
<link rel="stylesheet" href="patterns.css">
<section class="bg-waves">...</section>
```

Or reference the SVG directly:

```css
.hero { background: #0c0d10 url("patterns/waves.svg") repeat; }
```

Recolor by editing the `stroke` and `fill` hex values in the SVG.
